## 🏋️ FlexCoreGym

An e-commerce store for gym and fitness equipment, built with WordPress + WooCommerce. FlexCoreGym showcases and sells home gym gear — from exercise bikes and power racks to recovery tools like foam rollers and massage guns — with a clean, dark, high-contrast storefront design.

---

## ✨ Features

- **Hero Section** — Bold landing banner introducing the store
- **Shop** — Full product catalog grid with pricing, sale badges, and quick "Add to Cart" / "Select options" actions
- **On Sale** — Dedicated section highlighting discounted products
- **New Arrivals** — Section for newly added products
- **Cart** — Shopping cart with order overview
- **Checkout** — Multi-step checkout with contact info, shipping address, order summary, payment options, and coupon support
- **My Account** — Customer account management page
- **Fully Responsive** — Optimized mobile experience across shop, cart, checkout, and account pages, including a mobile navigation dropdown

## 🚀 Getting Started

1. Clone this repository
2. Set up a local WordPress environment (e.g. LocalWP, XAMPP, or Docker)
3. Install and activate the WooCommerce plugin
4. Import the theme/site files and product data into your WordPress installation
5. Configure payment and shipping settings in WooCommerce
6. Run the site locally or deploy to your hosting provider
